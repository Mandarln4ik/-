# NeuroForge v1.1.2

Исправление 404 при скачивании моделей с Hugging Face и снятие жёсткой привязки
бенчмарка к одной модели.

---

## Что было сломано

```
MobileNetV3-Small (int8) — NPU smoke test: HTTP 404 fetching
mobilenet_v3_small_int8_channelwise.tflite from litert-community/MobileNet-v3-small
```

Кнопка Download не работала. Бенчмарк снова был недостижим — уже по второй причине подряд.

## Причина

Имя файла в каталоге было **догадкой**. Я взял его из сниппета поисковой выдачи и не мог
проверить: Hugging Face недоступен из окружения, где собиралась сборка. Репозитории
переименовывают и переквантуют файлы, так что правдоподобное имя — это не имя.

## Исправление

Исправлено не имя, а подход. Приложение больше не полагается на то, что имя угадано верно:

1. Пробует объявленное имя.
2. Если 404 — запрашивает листинг репозитория через API Hugging Face.
3. Выбирает файл по подсказкам (`int8`, `dit`, `vae`…): больше совпадений выигрывает,
   при равенстве — более короткое имя, чтобы `model_int8.tflite` побеждал
   `model_int8_experimental_v2.tflite`.
4. Если ничего не подходит — сообщает, **что именно** лежит в репозитории, вместо «404».

Логика выбора — чистая функция `chooseModelFile()` в ядре, 7 тестов. Если подходящего
файла нет, она возвращает null, а не «наиболее похожий»: скачать не тот граф хуже, чем не
скачать ничего — ошибка всплывёт позже и в менее понятном месте.

## Бенчмарк больше не привязан к одной модели

Раньше он требовал именно смоук-тест, и когда его загрузка ломалась, функция становилась
недостижимой. Теперь подойдёт **любая скачанная модель с фиксированным входом** — в том
числе апскейлер ESRGAN, который качается с GitHub и проверен по контрольной сумме.

Апскейлер для этой роли даже уместнее: это и есть тот граф, который NPU реально должен
исполнять, так что его медиана — более полезное число, чем у классификатора.

**Практический вывод:** если смоук-тест почему-то не скачается, скачайте ESRGAN ×4 (4 МБ) —
бенчмарк отработает на нём.
